\section{Apical \texorpdfstring{$I_h$}{Ih} distance-dependent
gradient}\label{app:ih-gradient}
% =============================================================

The \texttt{cADpyr229} apical $I_h$ conductance follows BBP's
distance-dependent gradient
\[
  \bar{g}_{I_h}(d)
    = \bigl(-0.8696 + 2.087\,e^{0.0031\,d}\bigr)
      \cdot 8\!\times\!10^{-5}\;\mathrm{S/cm}^2,
\]
where $d$ is path distance from the soma in $\mu$m, computed by
NEURON's \texttt{distance()} from the soma section's 0 end. We
approximate $d$ with the Euclidean distance from each compartment to
the soma's geometric centre, which is close for roughly-vertical
apical trees and within a few $\mu$m of NEURON's reference along the
soma itself. Without the gradient
(uniform somatic value) the pre-stim resting-potential offset against
NEURON is markedly larger; the Euclidean approximation reduces it to
about $0.4\text{--}0.5\,$mV by stim onset (\cref{sec:res-neuron}).
A path-distance traversal would close it further
(\cref{sec:limitations}).
